# Changelog

## ver. 1 (2026)
- Dashboard 5 halaman: Ringkasan organik, Komparasi periode, Top Performance, Giveaway & kuis, Rekomendasi.
- Upload banyak file sekaligus: CSV, XLSX (tanpa internet), gambar dan PDF (lewat API key Gemini, opsional).
- Impor langsung CSV bawaan Meta (UTF-16, bahasa Indonesia maupun Inggris): klik tautan, pengikut, kunjungan profil, dll.
- Pemilih periode berupa kalender, dengan peringatan bila periode tidak ada di data.
- Komparasi periode: kolom kiri periode aktif, kolom kanan "Bandingkan dengan"; selisih = kanan dibanding kiri.
- Caption dipotong 8–10 kata dan bisa diklik ke postingan (kolom `url`/`permalink`).
- API key Gemini disembunyikan secara default, ada tombol "Hapus key".
- Mode terang/gelap, ekspor PDF.
